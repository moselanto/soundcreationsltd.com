# Competitor intelligence: Kenya (Deliverable B)

Site: <https://soundcreationsltd.com/> (Sound Creations Ltd, Nairobi). Not the
Rwanda site (soundcreationsltd.rw), which is covered in its own repository.

Research date: 19 Oct 2026. Method: web search (non-personalised index, not a
live Kenyan Google SERP), page fetches of competitor and manufacturer sites.

## Read this first: evidence rules

- **Observed** = seen on a fetched page or search result on 19 Oct 2026, with the URL.
- **Estimate / judgement** = my assessment, labelled as such.
- **Not available (n/a)** = no search volumes, rankings positions, traffic,
  domain authority or review counts were measured for competitors. None are
  invented here. "Appears for query X" means the page was returned by the
  research search engine for that query, **not** a verified Google.co.ke
  position. Verify positions in Google Search Console / a Kenyan-located
  rank check before acting on ordering.
- **Schema**: the fetch tool returns rendered text, not raw HTML, so
  `application/ld+json` could **not** be verified for any competitor. Every
  schema cell below is "not verified". Check with Google's Rich Results Test
  or view-source before relying on it.
- Google Business Profile ratings for competitors were not visible to the
  research tools: n/a unless a number is shown on the competitor's own site
  (self-reported, labelled as such).

## Conflict-of-interest note

VTECH Audio Visual Solutions (vtechaudio.co.ke) is also managed by the same
website project lead (Agnes), and its site lists **Ground Floor, Mpaka Plaza,
Mpaka Road, Westlands** — the same building as Sound Creations. Its pages
appear for the same commercial queries (sound system installation, church
sound, conferencing, acoustics). The two sites are therefore competing for
the same SERPs and the same local-pack area. This is an owner decision, not
an SEO one: either differentiate the two deliberately (e.g. VTECH =
events/LED/conferencing/hire; Sound Creations = acoustics engineering,
distribution, worship and venue integration) or accept cannibalisation.
Recommendations below are written for Sound Creations only and do not
suggest attacking VTECH content.
